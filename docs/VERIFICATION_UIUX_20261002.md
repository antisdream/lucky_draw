# 2026-10-02 UI/UX 검증

모바일 게임 위에 후보 수·선정 인원·반복 횟수·중복 설정 요약과 설정 변경을 제공한다. 오류는 해당 필드의 설명과 aria-invalid에 연결하고 그 필드로 초점을 이동한다. 준비·입력 확인·조작 대기·추첨 중·완료·취소 상태를 텍스트로 표시한다.

결과 전체 이름을 강조하며 새 추첨·설정 변경·복사·CSV 동선을 제공한다. 설정 변경 뒤에는 이전 결과임을 명시한다. 저장·도움말의 첫 섹션에 수동 기기 저장을 배치하고 저장 전·저장 안 된 변경·기기 저장됨을 표시한다. 후보·결과 자동저장은 추가하지 않았다. 기존 움직임 선호도의 별도 저장은 유지한다.

검증 결과:

- `npm.cmd test`: 69개 통과. 추첨 공정성·큰 정수·전체 회차 중복 금지·CSV·취소·건너뛰기·HTML 복원과 새 오류/저장/상태 회귀 검증 포함.
- `npm.cmd run build`: 독립 index.html과 dist 생성 통과. 외부 런타임 자산 없음.
- 로컬 Chromium: 네 게임, Enter 조작, 반복 클릭, 3회×2명, 취소 후 이전 결과 보존, 설정 변경, 긴 이름 전체 표시, CSV 32명과 결과 페이지, 복사, 수동 저장·미저장 표시·새 실행 복원, 내보낸 HTML 불러오기 통과.
- 320/360/390/768/1280px 홈 및 320×640, 640×360, 1280×800 경기 화면에서 문서 가로 넘침 없음. 360px 홈·긴 결과 스크린샷을 실제 열어 검토.
- 로컬 HTTP에서 명시적 웹 오프라인 준비 후 네트워크 차단·재탐색 통과. 파일 index.html 실행·추첨 통과. 운영 웹 주소의 인증/캐시 검증은 미실행.
