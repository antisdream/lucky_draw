# lucky draw. — 나만의 럭키드로우

룰렛, 다트, 냠냠 레이스, 꼬리잡기 중 원하는 게임으로 이름과 번호를 뽑습니다. **`index.html` 파일 하나를 열면 바로 실행됩니다.** 계정, 서버, 인터넷 연결, 프로그램 설치가 필요하지 않습니다.

## 내 컴퓨터에서 바로 실행하기

1. 이 GitHub 저장소 화면에서 초록색 **Code** 버튼을 누릅니다.
2. **Download ZIP**을 눌러 파일을 내려받습니다.
3. 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다. macOS에서는 ZIP을 두 번 클릭하면 됩니다.
4. 압축을 푼 폴더 안에서 **`index.html`을 두 번 클릭**합니다.
5. 게임 선택 화면이 나오면 준비가 끝났습니다. 인터넷 연결을 끊어도 계속 이용할 수 있습니다.

파일이 메모장이나 코드 편집기로 열리면 `index.html`을 마우스 오른쪽 버튼으로 눌러 **연결 프로그램 → Microsoft Edge 또는 Google Chrome**을 선택하세요. macOS에서는 **다음으로 열기 → Safari 또는 Google Chrome**을 선택합니다. 최신 Chrome, Edge, Firefox, Safari에서 사용하도록 작성했습니다.

다른 컴퓨터로 옮길 때는 **`index.html` 하나만** USB, 메일 첨부 등으로 전달하면 됩니다. 나머지 폴더는 실행에 필요하지 않습니다. GitHub의 코드 미리보기 화면에서는 게임이 실행되지 않으므로 파일을 내려받아 여세요.

## 추첨하는 순서

1. 첫 화면의 이름 칸에 모임이나 행사 이름을 입력합니다. 예를 들어 `우리 팀`을 넣으면 **우리 팀의 럭키드로우**가 됩니다. 한글·영어·공백을 사용할 수 있고 별도의 글자 수 제한이 없습니다.
2. 네 가지 게임 중 하나를 선택합니다.
3. **번호로 / 직접 입력 / CSV 가져오기** 중 후보를 준비할 방법을 선택합니다.
4. **한 번에 뽑을 인원**과 **반복 횟수**를 입력합니다.
5. 필요하면 **중복 당첨 허용**을 켭니다.
6. 게임 시작 버튼을 누릅니다. 결과는 화면 아래에 이름 전체와 회차별 순서로 표시됩니다.

휴대전화의 좁은 화면에서는 게임 화면 아래에 후보와 추첨 설정이 있습니다. 설정을 바꾼 뒤 게임 시작 버튼을 누르세요.

| 게임 | 진행 방식 |
| --- | --- |
| 럭키 룰렛 | 원판이 빠르게 회전하다 감속하고, 위쪽 포인터가 선정된 후보를 가리킵니다. |
| 다트 한 방 | 원판이 회전하고 날아온 다트가 선정된 후보의 구역에 꽂힙니다. |
| 냠냠 레이스 | 미로의 먹이를 따라 이동하다 선정된 후보를 마지막으로 먹습니다. |
| 꼬리 잡아라 | 후보들이 연결된 꼬리를 쫓아가 선정된 마지막 꼬리를 잡습니다. |

## 후보 넣기

### 번호를 자동으로 만들기

**번호로**에서 시작 번호와 후보 수를 입력합니다. 시작 번호 `1`, 후보 수 `100`이면 1번부터 100번까지 참여합니다. **번호 하나 추가**를 누르면 다음 번호가 하나 더 생깁니다.

번호는 쉼표 없이 정수로 입력하세요. `1000`은 가능하고 `1,000`, `1.5`, `1e3`은 사용할 수 없습니다. 시작 번호에는 0과 음수도 쓸 수 있습니다.

### 한 칸씩 직접 입력하기

**직접 입력**에서 각 칸의 번호를 원하는 이름이나 항목으로 바꿉니다. **번호로 후보 추가**를 누르면 기본 번호가 들어간 새 칸이 생깁니다. 각 칸 오른쪽의 `×`로 해당 후보를 삭제할 수 있습니다.

후보가 많으면 **한 번에 붙여넣기**를 누르고 한 줄에 한 명씩 넣습니다.

```text
김하늘
이바다
박별
오늘의 메뉴: 파스타
```

기존 명단에 더 넣으려면 **기존 후보에 이어서 추가하기**를 체크합니다. 체크하지 않으면 입력한 명단으로 교체합니다. 빈 칸과 빈 줄은 제외합니다. 쉼표는 이름의 일부로 유지합니다.

같은 이름이 두 칸에 있으면 **별도의 두 후보**입니다. 중복 없는 추첨이어도 같은 이름의 두 사람이 각각 선정될 수 있습니다. 구별이 필요하면 `김하늘 A`, `김하늘 B`처럼 적어주세요.

### CSV 또는 표 파일에서 가져오기

1. Excel이나 다른 표 편집기에서 번호와 이름을 열로 정리합니다.
2. **다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)**를 선택해 저장합니다.
3. 사이트에서 **CSV 가져오기**를 누르고 파일을 선택하거나 파일을 끌어놓습니다.
4. 첫 줄이 `번호,이름` 같은 제목이면 **첫 행은 제목이에요**를 켜 둡니다. 첫 줄부터 실제 후보라면 끕니다.
5. **추첨에 사용할 열**에서 이름 또는 번호 열을 선택합니다. 표시된 인원과 미리보기를 확인합니다.

예시는 [examples/candidates.csv](examples/candidates.csv)에 있습니다.

```csv
번호,이름
001,김하늘
002,이바다
003,"별, 하나"
```

탭으로 구분한 `.tsv`와 세미콜론으로 구분한 파일도 읽습니다. 쉼표가 들어간 이름, 큰따옴표, 셀 안의 줄바꿈을 지원합니다. 한글 파일을 읽지 못하면 **파일 인코딩 → 한국어 Windows (CP949)**로 바꾸세요. 선택한 열의 빈 셀은 제외합니다. 파일은 브라우저 안에서 읽습니다.

## 여러 명 또는 여러 회차 뽑기

| 원하는 결과 | 한 번에 뽑을 인원 | 반복 횟수 | 중복 당첨 허용 |
| --- | --- | --- | --- |
| 1명 선정 | 1 | 1 | 끄기 |
| 5명 선정 | 5 | 1 | 끄기 |
| 매 회차 2명씩, 3회 결과 | 2 | 3 | 끄기 |
| 번호 하나를 10회 추첨, 같은 번호 재선정 가능 | 1 | 10 | 켜기 |

중복을 끄면 **전체 회차에 걸쳐 같은 후보가 다시 뽑히지 않습니다.** 총 선정 인원이 후보 수보다 많으면 시작 전에 안내합니다. 모든 후보를 무작위 순서로 정하려면 후보 수와 한 번에 뽑을 인원을 같게 설정하세요.

기본 연출은 약 **3.4초**, 빠르게는 **1.8초**, 여유롭게는 **5초**입니다. **반복 횟수를 늘려도 연출은 한 번만** 보여주고 모든 회차의 결과를 함께 공개합니다. 여러 명을 뽑을 때 게임 연출은 첫 번째 선정 결과를 보여줍니다.

진행 중 **바로 결과 보기**를 누르면 연출을 건너뜁니다. **추첨 취소**는 진행 중인 추첨을 중단하며 일부 결과를 완료 결과로 표시하지 않습니다. **한 번 더 뽑기**는 새 추첨이므로 이전 결과와 독립적입니다.

## 후보와 설정을 담아 HTML로 저장하기

오른쪽 위 **HTML 저장**을 누르면 다음 내용을 담은 `lucky_draw.html`이 내려받아집니다.

- 입력한 주최자 이름과 선택한 게임
- 번호 범위, 직접 입력한 후보, CSV에서 선택한 후보
- 선정 인원, 반복 횟수, 중복 여부, 연출 시간
- 마지막으로 완료한 추첨 결과

이 **새 HTML 하나를 옮기면 같은 후보·설정·결과를 복원**합니다. 처음 받은 원본 HTML을 그대로 복사하면 원본의 초기 설정으로 열립니다. 변경한 내용을 가져가려면 반드시 화면의 **HTML 저장**으로 저장하세요.

입력 내용은 서버에 전송하지 않으며 브라우저 저장소에 자동 저장하지 않습니다. 저장 전 새로고침하거나 창을 닫으면 저장하지 않은 변경은 사라집니다. 저장된 HTML에는 후보 이름과 결과가 들어 있으므로 전달할 때 포함 내용을 확인하세요.

결과만 필요하면 **결과 복사** 또는 **CSV 저장**을 이용합니다. 결과가 많을 때 화면은 24개씩 나눠 보여주며 CSV에는 모든 결과가 들어갑니다. Excel의 수식 실행을 막기 위해 `=`, `+`, `-`, `@` 등으로 시작하는 CSV 값에는 작은따옴표가 붙을 수 있습니다.

## 후보 수와 속도

후보 수, 주최자 이름 길이, 선정 인원, 반복 횟수에 서비스가 정한 고정 상한을 두지 않았습니다. 다만 실제 컴퓨터의 메모리와 브라우저가 처리할 수 있는 데이터는 유한합니다.

번호 후보는 **범위만 보관**하고 큰 정수를 정확하게 계산합니다. 따라서 매우 큰 번호 범위에서 몇 명을 뽑는 경우에도 후보 수만큼 배열을 만들지 않습니다. 직접 입력한 이름과 CSV는 실제 명단을 메모리에 보관합니다. 선정 결과를 아주 많이 만들면 결과 수에 비례하는 메모리와 계산 시간이 필요하며, 이때는 설정한 연출 시간보다 오래 걸릴 수 있습니다. 계산 중에도 취소할 수 있습니다.

후보가 12명을 넘으면 게임 화면에는 대표 후보 일부만 표시합니다. **화면에 보이지 않는 후보도 추첨에 동일하게 참여합니다.** 긴 이름은 게임 안에서 줄여 표시하고 결과에서는 전체 내용을 보여줍니다.

## 소리와 움직임

- 효과음은 처음에는 꺼져 있습니다. 게임 오른쪽 위 `♪` 버튼으로 켭니다.
- `◌` 버튼은 움직임을 간결하게 바꿉니다. 기기의 움직임 줄이기 설정도 따릅니다.
- 게임, 설정, 결과는 키보드로 사용할 수 있으며 입력 오류와 진행 상태를 텍스트로 제공합니다.

## 화면이나 기능을 수정하기

게임을 이용하기만 한다면 이 과정은 필요하지 않습니다. 소스를 수정하고 새 HTML을 만들 때만 다음 단계를 따릅니다.

1. [Node.js 공식 사이트](https://nodejs.org/)에서 LTS 버전을 설치합니다. Node.js 20 이상이 필요합니다.
2. 프로젝트 폴더의 빈 곳에서 마우스 오른쪽 버튼을 누르고 **터미널에서 열기**를 선택합니다.
3. 다음 명령을 차례대로 실행합니다.

```powershell
node --version
npm.cmd ci
npm.cmd test
npm.cmd run build
```

`npm.cmd run build`가 끝나면 프로젝트의 `index.html`과 배포용 `dist/index.html`이 갱신됩니다. 실행 중 외부 패키지를 불러오지 않으며 현재 프로젝트는 별도의 npm 의존성도 없습니다.

소스를 고친 뒤에는 다시 `npm.cmd run build`를 실행하고 브라우저를 새로고침하세요. 터미널에서 웹 주소로 열려면 다음 명령을 실행합니다.

```powershell
npm.cmd run dev
```

터미널에 표시된 **http://localhost:4177**을 엽니다. 종료는 터미널에서 **Ctrl+C**를 누릅니다. macOS와 Linux에서는 위 명령의 `npm.cmd`를 `npm`으로 바꾸면 됩니다.

| 경로 | 역할 |
| --- | --- |
| `index.html` | 바로 실행하거나 옮길 최종 파일 |
| `src/shell.html` | 화면 구조와 기본 문구 |
| `src/style.css` | 색상, 배치, 반응형 화면 |
| `src/core.js` | 무작위 추첨, 큰 정수, CSV 처리 |
| `src/app.js` | 게임 연출, 입력, 결과, HTML 저장 |
| `scripts/build.mjs` | 소스를 독립 HTML 하나로 결합 |
| `scripts/serve.mjs` | 선택적으로 사용하는 로컬 미리보기 서버 |
| `tests/` | 추첨 규칙과 컨트롤러 테스트 |
| `examples/candidates.csv` | CSV 입력 예제 |
| `.openai/hosting.json` | 별도 Sites 미리보기의 정적 배포 설정 |

난수는 `crypto.getRandomValues`로 만들고 범위를 벗어난 값을 다시 뽑아 나머지 연산의 확률 편향을 피합니다. 중복 없는 추첨에는 지연 Fisher–Yates 방식을 사용합니다. 게임 애니메이션은 먼저 정해진 무작위 결과에 맞춰 재생합니다. 서버에 기록을 남기거나 변조를 검증하는 감사 시스템은 포함하지 않습니다.

검증 범위와 남은 확인 항목은 [검증 기록](docs/VERIFICATION.md), 변경 내용은 [PATCH_NOTES.md](PATCH_NOTES.md)에 정리했습니다.
